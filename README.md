# 新入社員研修 — 開発プロセスとソフトウェア開発技術

組込みソフトウェア開発部門に配属される新入社員向けの講義資料です。

## 概要

| 項目 | 内容 |
|------|------|
| 対象 | 機械系学部卒の新入社員（プログラミング経験は限定的）が中心。中途入社者も含む |
| 範囲 | 重点はライフサイクル（V字）と構成管理・変更管理。ソフトウェアの構造・機能安全は全体像のみ |
| 時間 | 60分 |
| 形式 | スライド講義 + 各セクションで問いかけ |

## ファイル構成

```
.
├── slides.md         # Marpスライド本体
├── speaker_notes.md  # スピーカーノート（話す内容・問いかけ・流れ）
├── tools_reference.md # 開発ツール早見表（配布用）
└── README.md
```

## 内容

| セクション | テーマ | 時間 |
|-----------|--------|------|
| 01 | 車載ソフトウェア開発とは（ライフサイクル・車載ならではの難しさ） | 6分 |
| 02 | V字開発（合意・確認・つながり・ウォーターフォール・V字（A-SPICE 4.0）・V&V・アーキテクチャ設計） | 20分 |
| 03 | 構成管理・変更管理（ベースライン・変更要求と影響分析・技術的負債） | 12分 |
| 04 | 開発ツールの地図（V字上のツール配置・静的解析・テスト・SILS/HILS・CI・レビュー） | 7分 |
| 05 | ソフトウェア工学とのつながり・チームで品質を守るための行動 | 5分 |
| Q&A | — | 5分 |

## スライドの表示方法

[Marp](https://marp.app/) を使用しています。

```bash
# CLIでHTMLに変換
npm install -g @marp-team/marp-cli
marp slides.md --html --no-stdin -o slides.html
```

または [Marp for VS Code](https://marketplace.visualstudio.com/items?itemName=marp-team.marp-vscode) 拡張機能でプレビューできます。

## 設計方針

各スライドは「痛み → なぜ → 解決策」の流れで口頭で話すことを前提に設計しています。スライド自体にはキーワード・図・箇条書きだけを載せ、説明はスピーカーノートに記載しています。

機械系出身者が「あ、それと同じだ」と思えるたとえを随所に入れています。工場での実務経験は前提にせず、一般的なものづくり（図面・設計変更・作業手順・測定）の話に寄せています。
